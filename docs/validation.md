- 28 vérifications HTTP supplémentaires sur deux configurations de société fictive : nom avec accent et esperluette échappé, domaines multiples, refus des sous-domaines et domaines ressemblants, inscription ouverte explicite, e-mails personnalisés, formulaires externes, menu et paramètres. Le relais mail réel, HTTPS, les sauvegardes/restaurations du serveur cible, le workflow SSH et les politiques GitHub de production nécessitent la configuration du propriétaire. Docker et les workflows distants n’ont pas été exécutés localement.
